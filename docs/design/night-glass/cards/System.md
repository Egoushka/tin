# System

Night glass is built from six constants, and every size, radius and colour on Home derives from one of them. That is what makes the parts agree: the search bar, app tiles and cards share one curve because 28 is half of 56; a row inside a card is concentric because 28 − 12 = 16; an icon's line matches the text stem beside it.

**Light means attention.** Nothing is coloured at rest; the primary action is white. Colour appears only as light behind the glass, and each light has one meaning: teal is now, violet needs you, red is broken. Stale data has no light and fades to 55%.
