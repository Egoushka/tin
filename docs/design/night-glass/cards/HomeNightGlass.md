# Home · Night glass

The same Home as the other skins, drawn in Night glass. Only the theme id on the phone changes (`data-theme="nightglass"`); layout, content and behaviour are shared.

From the top, everything a stock launcher does plus Yehor's layer:

- **Status bar** and the **glance**: clock, date, weather.
- **Today** (calendar agenda): the next events with the current one marked, travel time with when to leave, and clashes in the warn colour.
- **Needs you**: approvals, PRs to merge and replies owed, one count and a breakdown. Tapping opens the queue.
- **Readiness** from Oura: the score ring, sleep, and a nudge when recovery is low. The nudge is model-written, so it is italic.
- **Homelab** (box `hedzer`): a dot, green when all is up, red with the failed service named. **Alarm**: the next one.
- **Music** with the earbuds' battery (left · right) in the output line, so a separate earbuds widget is not needed.
- **Notification glance**: unread counts per app and the latest message.
- **Dock** (5 apps) and the **search bar** with the mic. Search covers apps, people, the web and the assistant; tap the mic to speak.

**Night glass.** Glass's frosted cards and Inter, set in Night glow's dark room. Nothing is coloured at rest: the mic and primary buttons are white. Light means attention: violet shines through the card that needs you, teal marks now, red marks broken. Every age is on the surface.
