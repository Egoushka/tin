# All apps and search

Three screens in Night glass, the v4 skin. The other skins draw the same layout from the same token names.

- **All apps** (swipe up on Home): suggested apps, then A–Z, search bar at the bottom.
- **Typing**: results grouped as apps, people, ask Tin, search the web. Enter opens the top result.
- **Voice answer**: the answer card rises from the search bar. Model-written text is italic. A reminder can be set by voice; anything irreversible (approve, merge) only opens the item and waits for a tap.
